# Resources — what we have to work with
*Reference, stated once; each state records what had been used by then. Updated 2026-09-19.*

## Data
- **MOCHI** (`/vast/projects/bonnen/naturalistic-navig/MOCHI/`): 2,019 odd-one-out trials with human accuracy and RT — barense 140, majaj/hvm 464, shapegen 548, shapenet 867. ShapeNet trials come from 1,054 known 3D objects; 897 have voxelisations; **706 trials** have a single-category object set and all objects voxelised — the working set. Images 1000², white ground. ShapeNet trials were selected adversarially.
- **ShapeNet** (`Dist-shift-data/blend-data/`): 12 categories; 36,488 objects with `model_normalized.solid.binvox` (128³) and `.json`; the **20,885 rendered training objects** (MOCHI excluded) are the bank used everywhere.
- **Training renders** (`Dist-shift-data/shapenet_rendered/`): ~2,000 objects per category × **15 fixed cameras** (Fibonacci sphere, radius 2, pyrender, yfov π/3, 224²) × 3 backgrounds (white/black/random) ≈ 313k images per background, with camera pose per image and per-category similarity tables (DINOv2-S features).
- **ShapeGen**: `.blend` files and 19,200 renders; no voxelisations (Blender needed for depth).
- **Derived** (this repo, `bank/`, ignored): descriptors d57 / voxel8-16-32 / bbox / multiview / volatility / structure; depth-map bank (313k × 2,048); MOCHI poses; the L1-norm audit tables (`../L1norm_vs_distshift/`).

## Models
- **Pretrained** DINOv2-L (`vit_large_patch14_reg4_dinov2`, timm, cached in `hf_cache/`); also the 8 encoders of the manuscript's margin table (`all_model_margins.csv`).
- **12 category fine-tunes** + `all_categories`, by the collaborator: LoRA r=16 α=8 on the frozen backbone, multi-similarity loss, Adam 1e-6, 30 epochs, 20k similarity-binned triplets/epoch, seed 42. Checkpoints in `Dist-shift/logs/…_|tag|/checkpoints/`; their MOCHI evaluations in `hida-tune/ShapeNet_OOD_Analyses/<cat>/ood_analysis_results.csv` (2,019 rows: margins, correctness, encoder-space distances). **Inherited cost**: ~12 × 2 GPU-h dedicated-equivalent ≈ 25 GPU-h (their runs took 6–30 h wall on shared GPUs).
- **Pipeline** (`Dist-shift/HIDA/hida-tune/`, owned by the collaborator, read-only): `train.py`, `create_csv_shapenet.py`, `evaluation/ood_distance_analysis.py`. We run private copies with two hard-coded paths redirected (`../knockout/scripts/`).
- **New models** (this project): knockout / knock-in fine-tunes, same recipe, in `../knockout/logs/`, evaluated to `../knockout/eval/`.

## Compute
- **Cluster**: PARCC Betty, account `bonnen-naturalistic-navig`. `dgx-b200`: 27 nodes × 8 B200 (180 GB), 28 CPUs per GPU, QOS `dgx`. `b200-mig45` / `b200-mig90`: one node each of quarter / half slices, need `--qos=normal`. `genoa-std-mem` / `genoa-lrg-mem`: CPU nodes (5.6 / 15.9 GB per core). Login node: shared, load ~65; fine for pandas, not for training.
- **Rates** (parcc.upenn.edu/about/rates, unsubsidised / subsidised): B200 **$4.51 / $1.00** per GPU-hour; mig90 $2.25 / $0.50; mig45 $1.13 / $0.25; Genoa CPU $0.028 / $0.010 per core-hour. Billing per minute is the max of the CPU and GPU weights (full B200 = 1000, mig45 = 250). **Account cap** 60M billing-minutes/year; 10.3M used as of 19 Sep (shared with the memzero project).
- **Unit costs for this project**: one fine-tune ≈ 2 GPU-h incl. evaluation (~3 min/epoch) ≈ **$9 / $2**; the full 50-run design ≈ $450 / $100; a descriptor bank ≈ $0.10; the 1,895-candidate search ≈ $0.10.
- **Environments**: `envs/torchfeat` (torch 2.8 cu128, timm, peft, hydra, wandb, loguru, cv2, sklearn) for GPU work; `~/.conda/envs/dev` (numpy, scipy, pandas, matplotlib, PIL, pymupdf) for analysis.
